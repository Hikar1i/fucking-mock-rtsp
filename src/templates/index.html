Local Mock RTSP Monitor

📖 功能说明

  • 如需开启/关闭摄像头推流，可前往项目 config.yaml → webcam.enabled 中配置
  • 如需开启/关闭视频文件流，可前往项目 config.yaml → video.enabled 中配置
  • 如需开启/关闭真实RTSP代理流，可前往项目 config.yaml → rtsp_proxy.enabled 中配置
  • 如需开启/关闭各流的网页预览，可前往项目 config.yaml → *.web_preview 中配置
  • 如需调整干扰效果参数范围（最大/最小/默认值），可前往项目 config.yaml → effects_limits 中配置
  • 如需配置IP访问白名单，可前往项目 config.yaml → server.allowed_ips 中配置
